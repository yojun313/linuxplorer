# Linuxplorer

FastAPI 기반 파일 탐색기. UnivDash의 전체 높이 사이드바와 Prompts의 모바일 가이드를 참고한 화면, 접기/펼치기, 모바일 폴더 메뉴, 5가지 파일 보기, 6종 테마와 라이트/다크 모드를 제공합니다.

상단 또는 사이드바의 **설정**에서 루트 디렉토리, 테마, 보기 방식, 목록 밀도, 미리보기, 모바일 다중 선택을 변경합니다. 루트는 서버 공통 설정으로 `.state/settings.sqlite3`에 저장되며 재시작 후에도 유지됩니다. 화면 설정은 브라우저에 저장됩니다.

## 실행

`.env.example`을 참고해 `.env`에 관리자 비밀번호, 루트 경로와 접속 도메인을 지정합니다. 기본 비밀번호 `changeme`는 허용되지 않습니다. `SECRET_KEY`는 32자 이상이어야 하며, 누락되거나 짧으면 `.state/session.key`에 임의의 키를 생성해 사용합니다. 기존의 약한 키로 발급한 로그인은 만료되므로 다시 로그인해야 합니다.

```sh
uv sync
pm2 start ecosystem.config.cjs
```

HTTPS 운영 환경에서는 `COOKIE_SECURE=true`와 정확한 `ALLOWED_HOSTS`를 설정합니다. 로컬 HTTP 개발에서는 `COOKIE_SECURE=false`로 설정합니다. HTTPS 프록시 외부와 HTTP 내부의 스킴 차이는 로그인 요청을 차단하지 않습니다. Host allowlist와 CSRF 토큰 검증은 유지됩니다. `/docs`, `/redoc`, `/openapi.json`은 인증 여부와 관계없이 비활성화되어 있습니다. 공식 [FastAPI 설정 문서](https://fastapi.tiangolo.com/tutorial/metadata/#openapi-url)를 따릅니다.

## 응답성과 작업 제한

- 모든 파일 조회 API의 동기 파일 작업은 이벤트 루프 밖의 전용 스레드 풀에서 실행합니다. 조회 8개, 검색 2개, 미디어 스트리밍 4개, 업로드 2개로 풀을 분리합니다. 로그인과 설정은 파일 조회 풀을 사용하지 않습니다. 포화 상태에서는 무제한 대기열을 만들지 않고 `503`을 반환합니다.
- 압축, 압축 해제, 복사, 이동, 폴더 다운로드 준비, 폴더 용량 계산은 별도 프로세스로 실행합니다. 최대 2개, 30초 제한이며 초과 시 프로세스를 종료하고 `504`를 반환합니다. 제한은 웹 프로세스별로 적용됩니다.
- 파일 스트림은 256KB 단위로 읽고, Range 응답은 최대 2MB로 제한합니다. 파일 전체에 대한 `WILLNEED` 디스크 사전 읽기를 요청하지 않습니다.
- 텍스트 미리보기는 앞부분 128KB만 읽습니다. 큰 이미지(16MB 초과)와 PDF(32MB 초과)는 자동으로 읽지 않고 다운로드 링크를 표시합니다. 숨겨진 보기의 이미지와 미리보기는 요청하지 않습니다. 파일을 바꾸거나 닫으면 이전 미리보기를 취소하고 영상 재생도 중단합니다.
- 폴더 목록은 최대 5만 항목 또는 2초 동안 조회합니다. 일부 목록만 조회됐으면 이를 표시합니다. 검색도 2초 동안 수행합니다. 폴더 목록을 열 때 모든 하위 폴더의 항목 수나 용량을 재귀 계산하지 않습니다.
- 업로드는 파일당 1GB, 한 번에 100개, HTTP 요청당 1GB까지 허용합니다. 압축 해제는 최대 1만 항목 / 2GB입니다. 시간 제한으로 중단된 복사·압축에는 일부 생성된 파일이 남을 수 있습니다.
- 개발용 자동 재시작과 PM2 파일 감시는 끄고 종료 대기는 5초로 제한합니다. PM2 설정은 7초 종료 제한과 384MB 메모리 재시작 기준을 제공합니다.

하나의 오래 걸리는 작업이 웹 이벤트 루프를 점유하지 않도록 격리했습니다. 디스크 장애, 커널의 중단 불가능한 I/O 대기, 시스템 전체 자원 고갈까지 애플리케이션이 차단할 수는 없습니다.

## 보안

로그인 쿠키는 HttpOnly/SameSite=Strict이며 HTTPS에서는 Secure를 사용합니다. 상태 변경 API와 로그인/로그아웃은 CSRF 검증을 적용합니다. 로그인 실패는 IP별 15분에 10회로 제한합니다(현재 단일 프로세스 메모리 기준). 실제 경로로 루트 경계를 확인하고 `.env`, 인증 키 디렉토리, 실행 상태, 시스템 민감 경로 및 특수 파일을 차단합니다. 심볼릭 링크는 목록에서 제외합니다. 업로드 파일명과 압축 멤버 경로를 검증하며 루트 자체의 삭제/이동/이름 변경을 차단합니다. HTML/SVG 파일 응답에는 별도 CSP sandbox를 적용하고 서버 내부 오류는 응답에 노출하지 않습니다.

## 검증

```sh
.venv/bin/python -m unittest discover -s tests -v
uv run --with playwright python -m unittest discover -s tests -v
```

브라우저 검증은 설치된 `/usr/bin/google-chrome`을 사용합니다. 임시 루트와 별도 서버에서 문서 접근 차단, 인증, 프록시 로그인, CSRF, 경로 탈출, 업로드, 압축 해제, 루트 저장/재시작 유지, 대용량 스트리밍 중 다른 API 응답, 스레드 풀 포화와 작업 시간 제한을 검사합니다. 브라우저에서는 320~1440px, 사이드바 접기/저장, 모바일 메뉴, 설정, 12개 테마 조합, 파일 열기를 검증합니다.
